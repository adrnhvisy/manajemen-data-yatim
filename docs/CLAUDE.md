## Instruksi untuk Claude Code Assistant

### Mode Coding

Gunakan mode vibe coding untuk development yang smooth dan efisien.

### Priority Guidelines

1. **PRD.md** - Pahami produk terlebih dahulu
2. **REQUIREMENTS.md** - Ketahui kebutuhan sistem
3. **DATABASE.md** - Pahami struktur data
4. **ARCHITECTURE.md** - Pahami arsitektur
5. **SECURITY.md** - Implementasi keamanan
6. **WORKFLOW.md** - Ikuti alur bisnis

### Coding Standards

- Follow Laravel best practices
- Use meaningful variable names
- Write clean, readable code
- Include comments for complex logic
- Follow PSR-12 coding standard

### Development Process

1. Read documentation first
2. Understand requirements
3. Design database/API
4. Implement features
5. Test thoroughly
6. Document changes
